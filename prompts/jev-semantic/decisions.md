# Existing decisions and their recorded rationale

These notes summarize checked-in implementation/history. They do not invent a design history or claim that deterministic fixtures establish model quality. References are local documents/tests and the commits that introduced or stabilized them.

| Existing decision | Supported rationale and evidence |
| --- | --- |
| Displayed/current UI attention is not necessarily current teaching focus. | Cues persist independently of display slots. Any supplied identity can be revised; offscreen A revision leaves B foreground. This separates semantic validity from display projection. [Slice III: optional relations and compatibility](../../docs/alive-cue-jev-proposals.md), [inspection tests](../../src/alive/inspection.test.ts); implementation `9e171e2`. |
| Same broad topic does not imply the same Cue. | Identity represents the teaching object; the literature fixtures preserve distinct Darcy observation/theme objects and Insight/Complexity development. Source overlap or equal selected asset text does not force merging. [Slice III: observability and regressions](../../docs/alive-cue-jev-proposals.md), [foundation notes](../../docs/alive-cue-foundation.md), [inspection tests](../../src/alive/inspection.test.ts). |
| Omission from bounded context is not semantic absence. | Finite Cue/part/source/option bounds can exclude the right target. Coverage is explicit so missing candidates are diagnosable separately from a wrong model selection. Required-context gaps block transport. [Stabilization contract](../../docs/alive-cue-jev-stabilization.md), [projection](../../src/alive/projection.ts); stabilization `b980150` and ranking/allocation follow-up `f9d4915`. |
| One primary realtime semantic change per inspection is a bounded implementation choice. | A grounded Choice selects one operation; remaining punctuation subranges can progress. The recorded limitation is that compound utterances may contain further semantic changes. Source/history are retained for the deferred Slice VII background semantics path, which would use the same writer. [Slice III remaining work](../../docs/alive-cue-jev-proposals.md), [stabilization: deferred behavior](../../docs/alive-cue-jev-stabilization.md). This is not a claim that one utterance has only one meaning. |
| Student/unknown authority is limited. | The current slice is teacher-centric: independent student assertions/corrections must not overwrite teacher-established meaning. More sophisticated adoption and student attention policies are deferred; exact explicit adoption remains a domain operation. [Foundation authority fixes](../../docs/alive-cue-foundation.md), [Slice III request decomposition](../../docs/alive-cue-jev-proposals.md), [authority](../../src/alive/authority.ts) and [reducer](../../src/alive/reducer.ts). The notes record fixes `8c69d32` and `dd3659a`. |
| Provider/schema failure must not become NO_CHANGE. | NO_CHANGE asserts understanding and consumes evidence; service failure establishes neither. Distinct transport/timeout/HTTP/malformed/invalid-choice/cancellation diagnostics preserve pending source and avoid false successful accounting. [Slice III compilation/accounting](../../docs/alive-cue-jev-proposals.md), [semantic adapter tests](../../server/semantic-jev.test.ts), [runtime failure tests](../../src/alive/inspection.test.ts). |

This extraction changes where static strings live, not these choices. Request snapshots were captured against main `316fc43` before extraction and are checked by [extraction.test.ts](evals/extraction.test.ts); full-request digests include instructions, dynamic criteria and state. Do not refresh them to conceal unintended wording changes. A deliberate future semantic change needs its own review and justified evaluation expectations.
